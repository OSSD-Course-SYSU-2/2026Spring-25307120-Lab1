# 🏆 HarmonyOS 10x10 动态五子棋

本项目基于 **HarmonyOS ArkUI** 框架开发，展示了声明式 UI 在交互式小游戏中的应用。项目已从基础井字棋升级为 10x10 规格，并引入了动态动画反馈与优化的扫描算法。

## 🌟 功能特性

* **10x10 规格棋盘**：提供 100 格阵位，相比传统棋盘增加了博弈深度与趣味性。
* **五子连珠规则**：率先在横、竖、斜向任意维度达成 5 子连线即判定获胜。
* **交互体验优化**：
    * **落子动画**：棋子生成时带有缩放动效（Scale Animation），交互反馈更自然。
    * **动态状态栏**：UI 主题颜色随当前操作玩家（蓝色 X / 橙色 O）实时切换。
* **获胜视觉反馈**：检测到获胜连线后，系统会自动锁定并高亮显示胜方路径。
* **局部扫描算法**：采用以落子点为中心的八向扫描机制，确保在大尺寸棋盘下依然保持极低的计算开销。

## 🛠️ 技术实现

### 1. 状态管理
利用 ArkTS 的 `@State` 装饰器实现响应式数据绑定。通过管理棋盘数组、当前轮次及获胜索引，实现 UI 与逻辑的同步刷新。

### 2. 动画实现
使用 `animateTo` 闭包管理状态变更，配合组件属性动画实现丝滑的视觉过渡效果。

### 3. 性能设计
针对大尺寸网格进行了渲染优化，通过 `ForEach` 结合 `Grid` 容器实现高效的组件排布与点击响应。
