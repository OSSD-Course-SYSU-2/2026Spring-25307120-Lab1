# 🏆 HarmonyOS Pro: 10x10 动态五子棋

这是一个基于 **HarmonyOS ArkUI** 框架开发的声明式 UI 小游戏。项目已从基础的井字棋进化为支持 10x10 大棋盘、动态动画反馈以及高效局部扫描算法的增强版本。

## 🌟 核心亮点

* **10x10 宏大战场**：突破传统 3x3 限制，提供更广阔的策略空间。
* **五子连珠规则**：在 100 格棋盘上，率先达成横、竖、斜向连续 5 子者获胜。
* **丝滑交互动画**：
    * **落子动效**：棋子采用 `scale` 缩放动画，从无到有“弹”出，告别生硬。
    * **动态主题**：状态栏颜色随玩家轮次（蓝色 X / 橙色 O）实时切换，沉浸感十足。
* **胜利高亮系统**：获胜瞬间自动锁定并高亮（绿色背景）连成一线的棋子，赋予玩家极强的成就感。
* **高性能扫描算法**：摒弃低效的全局遍历，采用以落子点为中心的 **“八向射线扫描算法”**，即使棋盘进一步扩大也依然流畅。

## 🛠️ 技术深度

### 1. 状态驱动 UI (State Management)
利用 ArkTS 的 `@State` 装饰器，实现数据模型与视图的解耦。通过 `winIndices` 数组动态控制网格的背景色和文字缩放，展示了 ArkUI 响应式布局的核心威力。
