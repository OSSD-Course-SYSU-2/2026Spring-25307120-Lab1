# 🏆 HarmonyOS 10x10 响应式动态五子棋

本项目基于 **HarmonyOS ArkUI** 框架开发，展示了声明式 UI 在高品质交互式小游戏中的深度应用。项目已从基础井字棋升级为 **10x10 旗舰规格**，并全新重构了**多端部署自适应架构**、**智能局部价值评估 AI 算法**以及**拟真 3D 玉石美学视觉体系**。

## 🌟 功能特性

* **一次开发，多端部署**：
    * **窄屏生态（手机端/sm）**：自适应切换为紧凑型纵向单栏布局，完美匹配单手握持体验。
    * **宽屏生态（平板/折叠屏/lg）**：自动重构为横向双栏分流排版，并利用富余空间激活大屏专属的“互动复盘日志”。
* **智能棋局评估 AI**：
    * 告别盲目随机，引入**局部价值评估算法**。AI 会在落子前检索全盘空位，实时计算四向轴线的“进攻分”与“防守分”，智能拦截玩家的活三、冲四，极具博弈挑战性。
* **国风拟真视觉美学**：
    * **榧木纹理棋盘**：采用 135° 细腻线性渐变与内收缩网格线，还原真实木质棋盘立体感。
    * **3D 曜石与玉石棋子**：摒弃传统平面字符，利用高级径向渐变（Radial Gradient）与多重软阴影，在真机上完美呈现圆形黑白棋子的微晶高光与玉石质感。
* **行棋谱与复盘日志**：
    * 实时记录每一回合的落子顺序与绝对坐标。大屏下**支持跨栏交互**——点击右侧任意步数，左侧棋盘对应棋子将触发高亮边框精准定位。
* **获胜视觉特效**：
    * 检测到五子连线后，系统锁定获胜路径并使其转为高亮翡翠绿，同时赋予棋子**无限循环的动态呼吸震荡效果**。

## 🛠️ 技术实现

### 1. 响应式布局与断点管理
利用 ArkUI 的 `mediaquery.matchMediaSync` 动态监听屏幕宽度，划分 `sm`、`md`、`lg` 三阶断点。利用容器的 `constraintSize`（约束尺寸）与 `aspectRatio(1)`（严格宽高比锁死），确保棋盘在任意屏幕尺寸和拉伸状态下，均保持 1:1 正方形不扭曲。

### 2. 多版本兼容性渲染保障
针对部分旧版鸿蒙 SDK 在 `Circle` 组件上应用复杂渐变时会溢出为方块的底层渲染缺陷，本项目创新性改用通用 `Column` 容器作为骨架，通过强行注入 `borderRadius(999)` 进行宿主包围框裁剪，在全版本系统上完美保障了正圆棋子的渲染品质。

### 3. 游戏状态机与局部动态动画
基于 ArkTS 的 `@State` 装饰器实现棋盘数据（一维序列化数组）、当前轮次及获胜索引的响应式双向绑定。配合 `animateTo` 闭包对状态变更进行平滑接管，实现了落子时带回弹效果的缓动动画。
